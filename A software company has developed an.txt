A software company has developed an Employee Management System to manage employee information and calculate salaries. All employees have common attributes such as Employee ID, Employee Name, and Basic Salary. To improve code reusability, the company has decided to use inheritance by creating a parent class named Employee. The company has three categories of employees: Junior Staff, Senior Staff, and Manager. Although the salary calculation method is the same for all categories, each category receives a different basic salary.

A Junior Staff member receives a basic salary of Rs. 60,000. In addition to the basic salary, the employee receives a House Allowance equal to 20% of the basic salary and a Transport Allowance equal to 10% of the basic salary. An EPF deduction of 8% of the basic salary is applied. Design a child class named Junior Staff that inherits from the Employee class and calculates the net salary.

A Senior Staff member receives a basic salary of Rs. 90,000. Similar to Junior Staff, the employee receives a House Allowance of 20% and a Transport Allowance of 10% of the basic salary. An EPF deduction of 8% of the basic salary is applied. Design a child class named SeniorStaff that inherits from the Employee class and calculates the net salary.

A Manager receives a basic salary of Rs. 150,000. The Manager also receives a House Allowance of 20% and a Transport Allowance of 10% of the basic salary, while an EPF deduction of 8% is applied. Design a child class named Manager that inherits from the Employee class and calculates the net salary.

The net salary for all employee categories is calculated using the following formula:

Net Salary = Basic Salary + House Allowance + Transport Allowance − EPF Deduction

Using inheritance, create a Java program that calculates and displays the net salary of each employee category. Demonstrate how the common salary calculation method can be inherited from the Employee class while allowing different employee types to have different basic salary values.
